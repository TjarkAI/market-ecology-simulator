How these indices are built

The weights are the ETF's. PassiveInvestor buys index_weight = fundamental value / sum of fundamental values, and exactly these weights are used here. A market-capitalisation weighting would need a share count per instrument. Here, though, the number of shares outstanding is a result of what the issuer has sold, not a property of the security.

Chained, not a ratio of sums. I(t) = I(t−1) · Σ w(t−1) · P(t)/P(t−1). The weights drift because the fundamental values diverge. A fixed sum would silently turn into a price-weighted index in which the sector with the largest number dominates.

Beta is a claim, not a setting. Beta model is the value the factor model gives this sector's fundamental value. Beta measured is the regression of the index's daily returns on those of the total market: what comes out of the order books. Over five seeds of 370 trading days each: TECH 1.40 → 1.38, HLTH 0.70 → 0.66, CONS 0.80 → 0.87, ENRG 0.90 → 1.19, FINL 1.20 → 0.92 (± 0.41). The range survives the passage into prices almost unchanged (0.70 against 0.72), unlike the correlations, which the README finds strongly damped. The order does not survive: ENRG and FINL swap places, and FINL scatters so widely that on a single run any statement about its beta would be a guess. That is exactly why the scatter is shown here as well.

Why two gap columns. A chained index sums weighted returns, so it is an arithmetic mean. The price series are much noisier than the fundamental values and accumulate the larger rebalancing premium along the way. After a year the total-market index therefore stands double digits above its fair-value index, without a single member being that far away. Gap members is the answer measured today, weighted price ÷ fair value. The two belong side by side, because otherwise the screen shows a number that cannot be found in any instrument. For an index of a single instrument both are identical.

None of this feeds back. The indices read prices that were formed anyway, draw no random numbers and change no state. The same seed gives a bit-identical run with and without this page.
